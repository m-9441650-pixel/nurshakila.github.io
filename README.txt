MY IT JOURNEY — VERSI KEMAS
============================

CARA BUKA:
1. Buka folder ini dalam Visual Studio Code.
2. Klik index.html.
3. Jika ada Live Server: klik kanan index.html > Open with Live Server.
   Jika tiada Live Server, anda juga boleh double-click index.html dari File Explorer.

ANDA TAK PERLU TYPE COMMAND DI TERMINAL UNTUK UBAH TEKS WEBSITE.
Untuk ubah isi, buka fail .html yang berkaitan dan edit teks terus.

8 HALAMAN:
- index.html       = Home
- profil.html      = Profil Diri
- kemahiran.html   = Kemahiran
- pendidikan.html  = Pendidikan & Kelayakan
- projek.html      = Projek / Hasil Kerja
- pengalaman.html  = Pengalaman & Pencapaian
- kerjaya.html     = Matlamat Kerjaya
- hubungi.html     = Hubungi Saya

PENTING — MASIH PERLU ISI MAKLUMAT SEBENAR:
- pendidikan.html: tahun, sijil/kelayakan, kursus
- projek.html: nama projek, tahun, penerangan, pautan/gambar sebenar
- pengalaman.html: program, pertandingan, kursus, pencapaian sebenar
- hubungi.html: semak nombor telefon supaya betul

AUDIO:
Fail audio telah dipendekkan kepada 1 minit mengikut arahan projek.
Arahan projek juga meminta gabungan lagu + rakaman suara sendiri.
Jadi, sebelum hantar projek, gantikan audio/portfolio-1min.mp3 dengan audio 1 minit yang mengandungi suara anda sendiri.

WARNA & FONT:
Reka bentuk menggunakan 3 warna utama sahaja (navy, biru, teal) serta putih/hitam.
Font menggunakan 2 keluarga utama sahaja.

GAMBAR:
Gambar profil yang digunakan pada Home ialah images/profile-edited.jpg.
Ia telah dicrop dan diselaraskan untuk paparan portfolio.
